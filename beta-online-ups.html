Beta Series Online UPS

Three-phase in, single-phase out. In-built isolation transformer, auto re-transfer static switch and manual bypass for single-phase loads on a three-phase supply. Parallel redundancy is optional.

Standard features

  • High-frequency PWM using IGBTs
  • In-built isolation transformer
  • Auto re-transfer static switch
  • Manual bypass
  • Extended battery back-up

Optional features

  • Static bypass
  • Input power factor 0.99
  • Parallel redundancy
