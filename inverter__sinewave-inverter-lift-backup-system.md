## Product Overview
Makvolt's Sinewave Inverters deliver uninterrupted power with minimal operating expenses. The company contrasts inverter performance against diesel generators, emphasizing that inverters "operate with the same efficiency at all load settings" while generators lose efficiency at partial loads.

## Features
- Microcontroller based PWM technology using Hi-Grade IGBTs with Peak Current Handling Capacity
- Pure Sinewave Technology which ensures Noiseless, Safe and Efficient Performance
- Wide input voltage and frequency range against harsh utility environment
- Built in high capacity battery charger
- Starts automatically, no user action required
- LCD displays Inverter status and offers easy access to measurements
- Eco-friendly, no fumes, no noise, no pollution

## Applications
- Lift Backup System
- Air conditioning units
- Petrol pumps, Water pumps, Electric Motor
